## Getting Started
1. Download 2.1.2.
2. Unpack. Run `FIFAModManager.exe`.
3. Point at the FC 27 install.
4. Import mods. Apply. Launch.
5. Notes in `files/notes/`.

Manager applies packs. Editor authors them. Same toolsuite.
